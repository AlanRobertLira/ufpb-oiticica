# Oiticica

Tema WordPress desenvolvido para os sites da Universidade Federal da Paraíba (UFPB).

## Sobre

O Oiticica é um tema WordPress voltado aos sites institucionais da UFPB, com recursos para notícias, eventos, agenda, editais, patentes, widgets, navegação e personalização visual.

## Preservação e migração

Em outubro de 2026, o repositório foi preservado e migrado de `gfleig/ufpb` para `AlanRobertLira/ufpb-oiticica`.

A migração preservou commits, autores, datas, branches e objetos Git existentes. Nenhum commit histórico foi reescrito.

A documentação e as alterações realizadas posteriormente representam uma nova etapa de manutenção e não modificam a autoria original.

## Funcionalidades

A versão preservada possui, entre outros recursos:

- notícias;
- agenda;
- eventos;
- editais;
- patentes;
- menus e áreas de widgets;
- imagens destacadas;
- logotipo personalizado;
- widgets institucionais;
- indicadores;
- integração com o catálogo da Editora UFPB;
- integrações com serviços institucionais;
- compartilhamento em redes sociais.

## Estrutura

- `assets/` - recursos auxiliares e Font Awesome;
- `css/` - folhas de estilo auxiliares;
- `fonts/` - fontes distribuídas com o tema;
- `img/` - imagens e elementos visuais;
- `js/` - JavaScript;
- `widgets/` - widgets personalizados;
- `functions.php` - funcionalidades e configurações principais;
- `style.css` - metadados e estilos principais.
