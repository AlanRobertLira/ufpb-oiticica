## Preservação do histórico

A migração foi realizada preservando os objetos e referências Git existentes.

Não foram utilizados:

- `git rebase` para reescrever o histórico;
- `git commit --amend` nos commits históricos;
- squash dos commits originais;
- `git filter-branch`;
- `git filter-repo`;
- procedimentos equivalentes destinados a substituir a autoria histórica.
